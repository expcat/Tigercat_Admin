# 路线图收尾与待验证事项

本文件只维护尚未验证的分支和当前演示边界。开发顺序见 [Roadmap](../Roadmap.md)，组件增强见 [上游需求](tigercat-upstream-requirements.md)。已验证项目从活动清单移除，历史由 Git 保留。

## 下一轮验证

- [ ] **UP-02 人工验收**：复核双端认证表单、个人中心演示说明、异常返回与嵌入内容。UP-12 已在隔离的真实 .NET 服务验证双端 2FA 启用 / 刷新 / challenge 登录 / 关闭、忘记密码、Header 改密，以及角色权限变更后刷新进入 403 / 恢复；InMemory / SQLite 共 114 项 HTTP 检查通过。真实 TOTP / 短信 / 邮件尚未接入，跨域站点的嵌入策略与实体设备操作仍需实际环境确认。
- [ ] **真实触摸拖放**：UP-05 的 Tasks 双端已通过 Chromium 原生触摸模拟：820px 下跨列移动、落点提示、释放写回与刷新保持，375px 下预览及取消。UP-09 的 Performance 双端 375px 已通过原生触摸提交、取消与释放，也验证鼠标排序、键盘提交 / Esc / Tab / 切 Tab 取消。实体触屏的跨列、滚动和释放仍待人工验收。
- [ ] **打印人工验收**：UP-04 已通过浏览器实际打印克隆验证 React / Vue 浅色与深色共 4 份 A4 PDF、16 页，分页、水印、重复表头及页眉页脚均已检查；操作系统打印对话框与实体打印仍待人工验收。
- [ ] **最终人工验收**：各批次已实现与自动验证的结果仍需用户确认，尚未归档。UP-12 的双端 Settings / Tickets 桌面、375 px、暗色及真实 2FA 共 14 张最终截图已由总控视觉复核；不代替实体触屏、操作系统打印和系统剪贴板在目标环境的验收。

## 当前实现的真实边界

| 范围 | 已有实现 | 尚待增强 |
| ---- | -------- | -------- |
| 内容与图库 | 文章字段、协作者和附件引用走 [内容 API](api/content.md)；原生文件选择上传后随正文保存并可刷新恢复；图库裁剪上传真实位图，标注持久化，文件详情可读取，见 [媒体 API](api/media.md)。UP-07 已核对旋转后 512 × 288 输出和像素结果 | 实体触屏操作待人工验收 |
| Settings / Tickets | Settings 的 Logo 使用原生文件输入，上传成功后预览，保存设置才持久化引用；取消、上传失败和保存失败保留已有值。Tickets 继续保存标题、分类、优先级和描述 | 工单附件尚未接入上传或持久化；界面明确提示，未提供无效文件选择器 |
| 定时任务 | 列表、新建、编辑、启停和 Gantt 窗口走 [Jobs API](api/jobs.md) | Cron / nextRun 为展示字段，无真实调度执行器和运行历史 |
| 数据导入 | 用户 CSV 解析、映射与校验走 [Import API](api/import.md)；后台逐行写入用户与角色并持久化真实进度和结果，GET 只读，刷新 / 重启续跑，双端提供结果页和失败行下载 | 仅支持用户追加、重复跳过；状态 / 头像、覆盖更新及其他业务目标未接入；失败行密码列为空，补填后重导 |
| 登录流程 | .NET 各数据库提供程序统一使用 EF 用户和会话，管理 / 注册 / CSV 导入账号可登录；禁用 / 删除清理会话，权限变更在下一次受保护请求生效。双端真实 2FA、找回密码、改密及权限刷新已验证，见 [认证契约](api/auth.md) 和 [前端规范](frontend.md#认证个人中心与异常恢复) | 演示码仍为 123456，真实 TOTP / 短信 / 邮件投递推迟；Mock 仅实现演示认证，不能等同 .NET 的安全保证。Hub 新连接拒绝失效会话，已有长连接未主动断开或逐消息复核 |
| 个人中心 | 用户名来自会话，2FA 状态走 API，加载失败可重试，启用需确认、可取消 | 手机、签名、偏好、统计和设备历史为明确标注的演示；未接资料或偏好保存接口 |
| Help / About | UP-10 / UP-11 提供 15 篇实际入口指南、搜索与 5 篇递增加载、空态和准确的 Mock FAQ；Anchor / ScrollSpy 绑定 Shell 滚动容器，Code / CopyButton 提供复制反馈；About 区分 API / UI 版本、支持故障重试和分区直接链接 | 反馈仅为演示提示；系统剪贴板、实体设备操作与最终人工验收待复核 |
| Reports | 概览与趋势走 [统计 API](api/dashboard-export.md)，预览与导出使用相同 days；PrintLayout.print() 隔离报表打印，DataExport customExport 下载 CSV / JSON / XLSX；双端浅 / 深色共 4 份 A4 PDF、16 页已验证 | 操作系统打印对话框与实体打印待人工验收；导出重新查询，数据变更后需刷新预览 |
| Performance | 12,000 日志 / 10,000 表格内存造数；双端桌面 / 375px / 暗色首尾、48px 行高、sticky 和内部滚动通过；鼠标、键盘与原生触摸模拟提交 / 取消 / 释放已验证 | 真实服务端大数据未接入；实体触屏待人工验收；不为演示引入另一套拖拽包装 |
| Analytics | 高层图与基元示例；预设和自定义区间按包含首尾的天数缩放示例规模，联动 KPI、趋势、热图与渠道明细 | 基元 ChartTooltip 固定关闭；Scatter 为固定示例，Heatmap 使用固定星期 / 时段生成样本后缩放；真实业务日期查询、坐标格式和进一步交互联动推迟 |

编辑器使用内置引擎；确定编辑需求后再评估 engine / highlighter。Help 的 Anchor / ScrollSpy 绑定 Shell 滚动容器；UP-10 的文章入口、搜索、分页和 FAQ 已实现并通过双端定向验证。

/500 是独立演示入口，未接全局请求失败跳转或错误边界；结合具体失败场景决定是否补全局兜底，避免把普通请求失败一律跳走。
