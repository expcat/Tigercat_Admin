# 路线图收尾与待验证事项

本文件只维护尚未验证的分支和当前演示边界。开发顺序见 [Roadmap](../Roadmap.md)，本轮问题见 [视觉 Review](frontend-visual-review.md)，组件增强见 [上游需求](tigercat-upstream-requirements.md)。已验证项目从活动清单移除，历史由 Git 保留。

## 下一轮验证

- [ ] **失败 / 空 / 加载路径**：按实际改动涉及的接口注入 5xx、空数组和加载失败；正常数据态、未知项目 / 审批空态、公共异常页已检查。
- [ ] **API 模式路由与会话**：真实后端受限路由直访、整页刷新、权限加载，以及 2FA / 忘记密码完整流程。Mock 中 Vue 用户页刷新、demo OTP 和 /users → 403 已通过；不再保留“Vue 刷新必定丢会话”的旧结论。
- [ ] **真实触摸拖放**：Tasks 与 Performance 在触屏上的跨列、滚动和释放。本轮只查看拖拽区 / 看板，没有重新执行重排，不沿用历史通过结论。
- [ ] **打印实际输出**：Reports 打印对话框、PDF 分页、水印、页眉页脚；屏幕预览不等于实际打印。
- [ ] **媒体结果**：真实位图裁剪 blob / canvas 尺寸与标注坐标；图库弹层显示和关闭已检查。

## 当前实现的真实边界

| 范围 | 已有实现 | 尚待增强 |
| ---- | -------- | -------- |
| 内容与图库 | 文章标题、正文、类型、标签、分类、栏目、发布状态走 [内容 API](api/content.md) | 协作者 / 附件为本地态；图库裁剪 / 标注未持久化；附件选择无上传闭环 |
| 定时任务 | 列表、新建、编辑、启停和 Gantt 窗口走 [Jobs API](api/jobs.md) | Cron / nextRun 为展示字段，无真实调度执行器和运行历史 |
| 数据导入 | 创建任务、只读 GET 轮询、刷新恢复结果走 [Import API](api/import.md)，后端服务推进演示进度 | 文件、映射、参数为本地演示，未真实解析文件与按行写入 |
| 登录流程 | .NET 已有 2FA、验证码和忘记密码端点；忘记密码可更新已有用户密码，见 [认证契约](api/auth.md) | 演示码仍为 123456，真实 TOTP / 短信 / 邮件投递推迟；本轮未改密 |
| Help / Reports | 帮助与报表为静态演示，Reports 使用 window.print() | 数据来源、帮助分页和实际打印待补 |
| Performance | 万级内存造数；首次挂载、内部滚动和表头本轮通过 | 真实服务端大数据与触摸拖拽未验；不为演示引入另一套拖拽包装 |
| Analytics | 高层图与基元演示 | 基元 ChartTooltip 固定关闭；Scatter / Heatmap 为静态数据，真实区间、坐标格式和交互联动推迟 |

编辑器使用内置引擎；确定编辑需求后再评估 engine / highlighter。Help 的 Anchor / ScrollSpy 绑定 Shell 滚动容器；已统一代码示例、地址和帮助说明，见 [VO-006](visual-review/2026-10-04/findings.md#vo-006)。

/500 是独立演示入口，未接全局请求失败跳转或错误边界；结合具体失败场景决定是否补全局兜底，避免把普通请求失败一律跳走。
